## 0.3.0 延续的声音功能

首次进入需要点击游戏上方的 **「开启配乐与音效」**，或右上「声音关闭」按钮。浏览器禁止未交互自动发声；旧版静音设置继续保留，不会强行解除。刷新后即使偏好为开启，也需要一次点击（开启按钮或开始飞行）解锁音频。

- 三套原创电子配乐：云海明亮旋律、星港悬浮琶音、夜城小调节奏；96 BPM、16小节／40秒循环，含和弦铺底、低音、琶音、主旋律和鼓组。
- 菜单、对局和结算使用不同能量编排，换场景时音乐及环境声交叉淡入。
- 环境层：云海风声、星港低频脉动、夜城雨幕；引擎音随移动与推进变化。
- 15类事件音效：界面、倒数、起飞、擦弹、加速、护盾、清场、破盾、碰撞、里程碑、新纪录、解锁、装备、转场、恢复。
- 推进有上升扫频气流；爆炸有低频冲击、衰减噪声和碎片；护盾破裂有高频短促质感，不是共用一声蜂鸣。
- 设置中分别调整背景音乐、动作音效、环境与引擎，音量0独立静音；可试听当前场景音乐及逐项动作音效。
- 暂停、设置和切后台默认停止，设置里只有主动试听会播放；回到对局需点击继续。停播会清除已调度声音，不补播后台积压。

[三场景配乐试听](artifacts/三场景配乐试听-0.3.0.wav)：30秒WAV，按云海／星港／夜城各10秒拼接，带短淡入淡出；这是程序离线渲染的配乐节选，不含实战音效或环境声。真实游戏按场景循环播放。

所有音乐与声音由本工程谱面及Web Audio合成，不依赖远程录音或付费素材。当前是合成电子风格，不声称真人录音或交响乐制作。耳机／扬声器听感和物理手机兼容仍需实机调音。

## 这一版怎么游玩

- 默认「道具航行」，也可选「经典挑战」，两模式纪录分开。
- 方向键／WASD，或直接在战场、下方控制区按住拖动；手机另有方向按钮。
- 实战机体缩为旧渲染的一半。浅青判定环半径7逻辑单位，机翼无碰撞；移速220单位/秒。
- 拖拽灵敏度0.5–2.0倍；最大速度与灵敏度分离，位移积压不超过24单位，松手立即停止。大型快速划动仍受最大移速限制，不是瞬移。
- Esc暂停；后台或单帧中断超过250ms自动暂停，需手动继续。
- 初始60发，每3秒+4发，300发封顶。50秒仅里程碑，不终止挑战。

## 道具与奖励

首次第6秒尝试生成，其后每8秒；最多同时2个，12秒后消失。采样当前安全点，若没有合适点则跳过，不保证未来弹幕不会经过该位置。

- **S 推进器**：移速+50%，持续8秒；重复拾取刷新，不叠加倍率。
- **H 护盾**：抵挡一次碰撞，同tick多弹安全，随后保护1秒；最多存1层。
- **P 清场脉冲**：将160逻辑单位范围内的弹幕回收到边缘，不永久减少规则中的弹幕总数。

靠近即可拾取，拾取有文字、音效和对应表现。经典模式绝不生成或应用道具。

## 场景与皮肤

动态航线：云海→轨道星港→夜雨都市→循环，每20秒换区，最后3秒交叉淡入；可起飞前选择固定场景。减少动态时环境停止滚动，场景淡入保留。

皮肤机库有预览、装备、锁定条件与保存：白隼和蓝梭初始开放，累计航行30秒解锁赤鸢，90秒解锁幽影。各机型轮廓／涂装／尾焰不同，性能一致。未解锁可以预览，不能装备。

累计航行在死亡结算或结束本局返回时记入，每局仅计一次；直接关闭页面不会记入未结算时长。数据均本地存储，无服务器防篡改，不是在线排行榜。0.1.0的旧纪录迁移至单独历史字段，在操作说明中可查看，不混入0.2.0新规则。
